# Mods do servidor Minezasso dos Guri da Metah

Mods usados no servidor (NeoForge). **Para baixar:** vá em [Releases](../../releases/latest) e pegue o
**`mods.zip`** — ou baixe direto:

**[⬇️ mods.zip (versão mais recente)](../../releases/latest/download/mods.zip)**

## Como instalar
1. Instale o NeoForge da mesma versão do servidor.
2. Extraia o `mods.zip`: sai uma pasta `mods`.
3. Copie os `.jar` para `%appdata%\.minecraft\mods` (apague os mods antigos que foram removidos).

Cada Release lista o que foi **adicionado**, **atualizado** e **removido**. Os `.jar` atuais também ficam na pasta [`mods/`](mods).

## Avisos
Este repositório é atualizado automaticamente a partir da pasta de mods do servidor.
Os mods pertencem aos respectivos autores e seguem as licenças deles. Se você é autor e quer que um mod seja
retirado, abra uma issue.
